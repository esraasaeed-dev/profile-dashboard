# Profile Dashboard

A responsive profile dashboard built with **HTML, CSS, and Sass**, featuring social media links and project cards displaying their names and tech stacks.

## Technologies & Concepts

* HTML
* CSS
* Sass (SCSS)
* CSS Grid
* Flexbox
* Responsive Design
* Media Queries through Sass Mixins
* CSS Variables
* Transitions & Transform
* Hover Effects
